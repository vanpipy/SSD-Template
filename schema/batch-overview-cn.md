# 批次概览: [主题]

> **视角：执行 Prompt 1（会议摘要拆分）的 Agent**
> 批次概览是 **Agent 拆分会议摘要的产物**，不是参与人主动维护的文件。
> - Agent 在 Prompt 1 中负责：拆分 Collection、生成 batch-overview、维护跨 Collection 关系。
> - 参与人只在评审时扫一眼，确认拆分是否合理；日常维护由 Agent 负责。
> - 下游 Agent（Prompt 3 收敛讨论、Prompt 4 生成技术设计）读 batch-overview 作为全局上下文，理解 Collection 间的关系。
> - 一个批次只有一份批次概览，由 Agent 随 Collection 变化同步更新。

> 本模板分为**必填区**和**补充区**。
> - **必填区**：Agent 在创建批次时必须填写。
> - **补充区**：Agent 在后续收敛过程中随 Collection 更新同步补全。
