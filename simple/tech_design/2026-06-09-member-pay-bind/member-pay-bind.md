## 关键决策 (Key Decisions)

### KD-1: 支付即会员流程的触发时机与超时策略

**背景 (Context)**: 扫取付款码后，需先通过支付中心获取 openid/alipayuid，再查询会员，整个过程不能阻塞支付。需要决定超时阈值和超时后的行为。

**决定 (Decision)**: 扫码后整个支付即会员流程（获取身份标识 + 会员查询）设置总超时 3s；超时或任何异常均直接进入支付扣款，不等待、不提示店员。

**备选方案 (Alternatives)**:

| 选项 | 优点 | 缺点 |
|------|------|------|
| 总超时 3s，失败直接支付 | 不阻塞支付，体验好 | 网络慢时会员权益可能丢失 |
| 单步超时（获取身份 1s + 查询 2s） | 分段控制更精细 | 实现复杂，最坏情况仍 3s |
| 无超时，失败才跳过 | 无丢失风险 | 网络异常时可能长时间阻塞支付 |

**理由 (Rationale)**: PRD 明确"任何查询环节失败均不阻塞支付"；收银场景对支付速度敏感，3s 总超时在正常网络下已足够完成查询，异常情况下快速降级优先保障支付。

**如何强制 (Enforced by)**: 单元测试模拟超时场景验证降级路径；code review 确认无同步等待阻塞 UI 线程。

---

### KD-2: 会员查询到后的金额重算确认流程

**背景 (Context)**: 查询到会员后需重新计算促销，展示新金额由店员确认后再发起支付。需要决定重算和确认的交互方式。

**决定 (Decision)**: 查询到会员后，自动绑定至订单并触发服务端重新计算促销，返回新金额后在支付确认页更新展示；若新金额与原金额不同，高亮提示变化，店员确认后发起扣款。

**备选方案 (Alternatives)**:

| 选项 | 优点 | 缺点 |
|------|------|------|
| 弹窗确认新金额 | 明确告知店员 | 增加额外弹窗，打断支付流程 |
| 直接在支付页更新金额，无需额外确认 | 无弹窗，流畅 | 店员可能未注意到金额变化 |
| 在支付确认页高亮展示差额，店员主动确认 | 无弹窗，有明确视觉提示 | 需要 UI 设计配合 |

**理由 (Rationale)**: PRD 要求"店员确认后发起支付"但也要求"对店员和顾客透明，无额外弹窗打断"；在已有的支付确认页高亮金额变化，既满足确认要求又无额外弹窗。

**如何强制 (Enforced by)**: UI 测试验证金额变化时高亮展示；code review 确认金额不同时有视觉区分。

---

### KD-3: 门店支付即会员开关的读取方式

**背景 (Context)**: 支付即会员功能依赖门店开关，开关关闭时应直接跳过整个流程进入支付。需要决定开关读取时机和缓存策略。

**决定 (Decision)**: 门店开关在登录后随门店配置一起拉取，缓存至本地 ViewModel；每次发起支付时读取本地缓存，无需实时请求；门店配置刷新时更新缓存。

**备选方案 (Alternatives)**:

| 选项 | 优点 | 缺点 |
|------|------|------|
| 发起支付时实时查询开关 | 始终最新 | 额外网络请求，增加支付延迟 |
| 登录时拉取并本地缓存 | 无额外请求，支付链路简洁 | 运营修改开关后需等下次登录才生效 |

**理由 (Rationale)**: 门店配置变更频率极低，本地缓存已足够；支付链路需要尽量精简，避免引入额外网络依赖。

**如何强制 (Enforced by)**: 约定门店配置接口包含支付即会员开关字段；code review 确认支付流程读取缓存而非实时请求。

## 数据模型 (Data Models)

### StoreConfig（本地缓存，登录时拉取）

| 字段 | 类型 | 说明 |
|------|------|------|
| storeId | string | 门店 ID |
| memberPayBindEnabled | boolean | 支付即会员开关 |
| supportedChannels | string[] | 支持的渠道：WECHAT / ALIPAY |

**约束**:
- 登录成功后拉取，缓存至内存
- 本期仅 WECHAT 和 ALIPAY 支持支付即会员

**关联场景**: 场景1-4（所有场景均先读取此开关）

---

### PaymentCodeIdentity（支付中心返回）

| 字段 | 类型 | 说明 |
|------|------|------|
| channel | string | 支付渠道：WECHAT / ALIPAY |
| openId | string? | 微信 openId（微信渠道） |
| alipayUid | string? | 支付宝 uid（支付宝渠道） |

**约束**:
- 微信渠道时 `openId` 不为空
- 支付宝渠道时 `alipayUid` 不为空

**关联场景**: 场景1（付款码反查到会员）

## API 契约 (API Contracts)

### 通过付款码获取身份标识

- **端点**: `POST /api/v1/payment/identity`
- **用途**: 通过扫取的付款码从支付平台获取用户身份标识
- **来源**: PRD 场景1（付款码反查到会员）、场景3（查询环节失败）

**请求**:
```json
{
  "paymentCode": "string, required — 扫取的付款码内容",
  "channel": "string, required — 支付渠道：WECHAT / ALIPAY"
}
```

**响应（成功）**:
```json
{
  "code": 0,
  "data": {
    "channel": "WECHAT",
    "openId": "oXXXXXXXXXXXXX",
    "alipayUid": null
  }
}
```

**响应（失败）**:
```json
{
  "code": 5001,
  "message": "获取身份标识失败"
}
```

**前置条件**: 已扫取到付款码
**后置条件**: 无状态变更
**副作用**: 无

---

### 通过身份标识查询关联会员

- **端点**: `POST /api/v1/member/query-by-identity`
- **用途**: 通过支付平台身份标识查询关联会员
- **来源**: PRD 场景1（付款码反查到会员）、场景2（未关联会员）

**请求**:
```json
{
  "channel": "string, required — WECHAT / ALIPAY",
  "openId": "string, optional — 微信 openId",
  "alipayUid": "string, optional — 支付宝 uid"
}
```

**响应（成功）**:
```json
{
  "code": 0,
  "data": {
    "memberId": "member_001",
    "nickname": "张三",
    "phone": "138****0000",
    "memberLevel": "gold"
  }
}
```

**响应（未关联）**:
```json
{
  "code": 4005,
  "message": "付款码未关联会员"
}
```

**前置条件**: 已成功获取身份标识
**后置条件**: 无状态变更
**副作用**: 无

---

### 绑定会员至订单

- **端点**: `PATCH /api/v1/order/{orderId}/member`
- **用途**: 将查询到的会员绑定至当前草稿订单，触发重新计算促销
- **来源**: PRD 场景1（查询到会员后自动绑定并重算）

**请求**:
```json
{
  "memberId": "string, required — 会员 ID"
}
```

**响应（成功）**:
```json
{
  "code": 0,
  "data": {
    "orderId": "order_001",
    "totalAmount": 88.00,
    "discountAmount": 12.00,
    "payableAmount": 76.00
  }
}
```

**前置条件**: 订单存在且状态为"已制单"
**后置条件**: 订单绑定会员 ID，促销重新计算
**副作用**: 无

## 降级策略 (Fallback Strategy)

### 降级场景: 获取身份标识失败或超时

- **触发条件**: 支付中心接口失败/超时，或总流程超过 3s
- **降级行为**: 跳过会员查询，直接发起支付扣款
- **业务影响**: 顾客本次支付不享受会员权益，支付正常完成
- **恢复条件**: N/A（本次交易已跳过，不补偿）

### 降级场景: 会员中心查询失败

- **触发条件**: 会员查询接口返回 5xx 或超时
- **降级行为**: 同上，直接发起支付扣款
- **业务影响**: 同上
- **恢复条件**: N/A

## 错误处理 (Error Handling)

| 错误码 | 含义 | HTTP 状态 | 处理 |
|--------|------|-----------|------|
| 4005 | 付款码未关联会员 | 404 | 跳过绑定，直接支付，对店员无感知 |
| 5001 | 支付中心不可用 | 5xx | 降级，直接支付 |
| 5002 | 会员中心不可用 | 5xx | 降级，直接支付 |
| TIMEOUT | 总流程超时 | — | 降级，直接支付 |
