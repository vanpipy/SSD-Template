# 移动收银APP · 订单全流程需求文档（完整版）

## 1. 功能模块概述

| 项目 | 内容 |
|------|------|
| 模块定位 | 管理从加购商品到订单最终完成（含库存调整）的完整业务流程，确保商品加购、促销计算、结算、支付、状态流转及库存扣减的正确性与实时性。 |
| 包含流程 | 草稿订单创建、商品加购与修改、实时价格与促销计算、结算（草稿转正式）、支付（含支付即会员）、支付成功/失败处理、订单完成、库存调整。 |
| 优先级 | P0（收银核心流程） |
| 前置条件 | 门店已注册、设备已绑定、收银员已登录、网络正常。 |
| 会话规则 | 一个收银会话仅对应一个草稿订单，结算后生成正式订单，草稿订单清除。草稿状态支持实时修改，正式订单生成后锁定内容不可修改。 |

## 2. 业务规则

| 编号 | 规则 |
|------|------|
| 1 | 首次加购时，移动收银APP请求聚合服务创建草稿订单，订单状态为“已创建”，关联门店、款台、设备、收银员。草稿订单不锁定商品价格，每次加购/修改时重新取价并计算促销。 |
| 2 | 加购/修改商品时，APP调用聚合服务更新草稿订单。聚合服务转发至订单中心，**同时聚合服务直接请求商品中心查询商品最新价格（含会员价）**，并将价格信息同步更新至订单中心。订单中心再调用促销引擎重新计算订单级优惠（满减、折扣等），更新订单金额及优惠明细。 |
| 3 | 商品取价由商品中心统一处理：优先查询门店零售价/会员价，若无则取档案零售价/会员价。多规格商品若使用非基本单位且无独立调价记录，按 `基本单位价格 × 换算系数` 计算。所有价格保留2位小数。 |
| 4 | 实时促销：每次商品变动后，聚合服务将订单明细及会员信息（若有）发送至促销引擎，促销引擎返回每项优惠明细及优惠总金额。促销计算不影响商品单价，仅影响订单级优惠。 |
| 5 | 结算：用户点击“结算”按钮后，APP请求聚合服务，聚合服务转发至订单中心，保存订单并将状态更新为“已制单”。此时聚合服务重新拉取所有商品最新价格（防止价格变动）、重新计算促销，并保存订单快照（包含流程信息、基础信息、会员信息、商品信息，不含优惠明细）。 |
| 6 | 支付即会员：若结算时订单未绑定会员，且门店开启了对应支付渠道（微信/支付宝）的支付即会员开关，则在扫付款码后，聚合服务请求支付中心解析付款码获取 `openid`/`alipayuid`，再调用会员中心查询是否关联会员。若为会员则自动绑定至当前订单并重新计算促销（如会员价），然后进入支付流程。若非会员或查询失败，直接发起支付。 |
| 7 | 支付流程：订单进入待支付状态后，APP调用支付中心发起扣款。支付中心返回支付结果（成功/失败/处理中）。支付成功时，订单状态更新为“已支付”；支付失败时，状态回退至“待支付”（可重试支付）。 |
| 8 | 订单完成：支付成功后，聚合服务触发订单中心保存订单的完整信息（商品信息、优惠信息、支付信息），保存成功后，订单状态自动流转为“已完成”。订单中心在订单完成后，异步通知库存中心扣减库存。 |
| 9 | 库存调整：订单完成后，订单中心请求库存中心接口，传入（门店ID、商品ID、规格ID、数量），进行库存扣减（若业务为出库减少库存，则扣减；若为退货则增加，本流程为正常销售扣减）。 |
| 10 | 订单状态更新触发节点包括：加购第一个商品、点击结算、发起支付、收到支付结果、切换购物车（挂单）、整单取消。这些操作均会触发订单状态的相应变更。 |
| 11 | 定时任务更新订单状态：需与开发团队讨论确定是否需要（如支付中超时自动取消、已完成超时自动评价等）。 |

## 3. 业务时序图

```mermaid
sequenceDiagram
    participant Cashier as 收银员
    participant App as 移动收银APP
    participant Agg as 移动收银聚合服务
    participant Order as 订单中心
    participant Product as 商品中心
    participant Price as 价格中心
    participant Promotion as 促销引擎
    participant PayCenter as 支付中心
    participant Member as 会员中心
    participant Stock as 库存中心

    Cashier->>App: 首次加购商品
    App->>Agg: 创建草稿订单(storeId, deviceId, cashierId)
    Agg->>Order: 创建订单(状态=已创建)
    Order-->>Agg: 返回draftOrderId
    Agg-->>App: 返回draftOrderId
    App->>Agg: 加购商品(draftOrderId, barcode, qty)
    Agg->>Product: 查询商品价格(barcode, storeId, 会员标识)
    Product->>Price: 取价(门店/档案优先级)
    Price-->>Product: 返回价格
    Product-->>Agg: 返回商品信息及价格
    Agg->>Order: 更新商品明细(价格)
    Agg->>Promotion: 重新计算促销(draftOrderId)
    Promotion-->>Agg: 返回优惠明细、应付金额
    Agg-->>App: 返回购物车详情
    App->>Cashier: 展示购物车

    Cashier->>App: 点击结算
    App->>Agg: 请求结算(draftOrderId)
    Agg->>Product: 重新拉取所有商品最新价格
    Product-->>Agg: 返回最新价格
    Agg->>Promotion: 重新计算促销(锁定)
    Promotion-->>Agg: 返回最终优惠
    Agg->>Order: 保存订单快照，状态变更为“已制单”
    Order-->>Agg: 返回正式订单号
    Agg-->>App: 返回订单信息
    App->>Cashier: 展示订单金额，引导支付

    Cashier->>App: 出示付款码
    alt 未绑定会员且支付即会员开关开启
        App->>Agg: 请求支付(orderId, paymentCode)
        Agg->>PayCenter: 解析付款码获取openid/alipayuid
        PayCenter-->>Agg: 返回身份标识
        Agg->>Member: 查询是否关联会员
        alt 是会员
            Member-->>Agg: 返回会员信息
            Agg->>Order: 绑定会员，重新计算促销
            Order->>Promotion: 重新计算会员价
            Promotion-->>Order: 返回新金额
            Order-->>Agg: 更新应付金额
            Agg-->>App: 金额变化，需店员确认
            App->>Cashier: 展示新金额，确认支付
        else 非会员
            Member-->>Agg: 无会员
            Agg->>App: 继续原金额支付
        end
    end
    Agg->>PayCenter: 发起扣款(orderId, amount, paymentCode)
    PayCenter-->>Agg: 支付结果
    alt 支付成功
        Agg->>Order: 更新订单状态为“已支付”
        Order-->>Agg: 成功
        Agg-->>App: 支付成功
        App->>Cashier: 支付成功页面
    else 支付失败
        Agg->>Order: 状态回退“待支付”或“已制单”
        Agg-->>App: 失败原因
        App->>Cashier: 提示失败，可重试
    end

    Cashier->>App: 点击“完成订单”
    App->>Agg: 请求完成订单(orderId)
    Agg->>Order: 保存完整订单信息(商品、优惠、支付)，状态变更为“已完成”
    Order->>Stock: 异步扣减库存(门店ID, 商品ID, 规格ID, 数量)
    Stock-->>Order: 扣减结果
    Order->>Order: 记录库存调整日志
    Order-->>Agg: 订单完成
    Agg-->>App: 完成成功
    App->>Cashier: 跳转至订单列表
