# 优先级推导矩阵

## 核心公式

`优先级 = 关键程度 × 使用频率`

## 矩阵

| 关键程度 \ 使用频率 | 高频 | 中频 | 低频 |
|---------------------|------|------|------|
| **关键**（交易/资金/数据正确性）| P0 | P0 | P1 |
| **重要**（功能完整性/状态一致）| P1 | P1 | P2 |
| **一般**（体验/展示/辅助）| P2 | P2 | P3 |

## 级别定义

| 级别 | 含义 | 典型场景 |
|------|------|---------|
| P0 | Blocker | 交易成功率、支付金额计算、核心主流程 |
| P1 | Critical | 订单状态流转、重要校验逻辑、权限控制 |
| P2 | Major | 筛选条件组合、数据导出、辅助功能 |
| P3 | Minor | 极端输入长度、极端并发、罕见硬件组合 |

## 关键程度推导

| 来源 | 判断 |
|------|------|
| PRD Goal 中的核心功能描述 | → 关键 |
| Tech Design ards.md 数据一致性要求（存量 v3：decisions.md）| → 关键 |
| 涉及资金/交易/数据正确性 | → 关键 |
| 功能完整性/状态一致性 | → 重要 |
| 体验/展示/辅助 | → 一般 |
| PRD Out of Scope 排除的内容 | → 不在范围 |

## 使用频率推导

| 来源 | 判断 |
|------|------|
| Scenarios 中出现次数多、多场景共享 | → 高频 |
| 主路径上的步骤 | → 高频 |
| 仅特定分支才走到的路径 | → 低频 |
| 管理后台/配置类操作 | → 低频 |

## 示例（支付模块）

| 功能点 | 关键程度 | 使用频率 | 优先级 |
|--------|---------|---------|--------|
| 支付金额计算 | 关键 | 高频 | **P0** |
| 交易成功率/回调 | 关键 | 高频 | **P0** |
| 订单状态流转 | 重要 | 中频 | **P1** |
| 支付页面展示 | 一般 | 高频 | **P2** |
| 极端金额边界 | 关键 | 低频 | **P1** |
