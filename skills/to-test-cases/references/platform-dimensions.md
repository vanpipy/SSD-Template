# 平台特异性维度

每次生成仅针对一个目标平台，按以下维度提取该平台特有的测试点。

## 通用维度（所有平台）

| 维度 | 测试关注点 |
|------|-----------|
| 网络行为 | 弱网、离线缓存、网络切换（WiFi→4G）|
| 异常恢复 | 崩溃恢复、数据持久化、断点续传 |

## iOS 特有

| 维度 | 测试关注点 |
|------|-----------|
| 手势交互 | 滑动返回、边缘手势、长按、3D Touch |
| 动态权限 | 权限弹窗时机、拒绝后引导、权限回收 |
| 生命周期 | 后台挂起、进程回收、状态恢复 |
| 键盘 | 系统键盘遮挡、键盘类型切换、剪贴板 |
| 通知 | 推送通知、横幅、应用内通知 |
| 硬件 | Face ID/Touch ID、NFC、相机权限 |
| 系统打断 | 来电、低电量弹窗、系统更新提示 |

## Android 特有

| 维度 | 测试关注点 |
|------|-----------|
| 返回键 | 物理/虚拟返回键、返回栈管理 |
| 权限模型 | 运行时权限、权限组、永久拒绝 |
| 生命周期 | Activity/Fragment 重建、进程优先级 |
| 碎片化 | 不同厂商 ROM、屏幕尺寸、分辨率 |
| 通知栏 | 通知渠道、前台服务、通知点击跳转 |
| 后台限制 | Doze 模式、后台执行限制、电池优化 |
| 多窗口 | 分屏、画中画、自由窗口 |

| 维度 | 测试关注点 |

| 键盘导航 | Tab 顺序、快捷键、快捷键冲突、焦点管理 |
| 窗口管理 | 多窗口、最小化/最大化、拖拽、DPI 缩放 |
| 鼠标交互 | 右键菜单、悬浮提示、拖拽排序、滚轮 |

| 文件关联 | 文件打开方式、拖放文件、默认程序 |

## Web 端

| 维度 | 测试关注点 |
|------|-----------|
| 浏览器兼容 | Chrome/Firefox/Safari/Edge 差异 |
| 响应式 | 不同视口宽度、缩放、横竖屏 |
| 缓存 | 浏览器缓存、Service Worker、CDN |
| 安全 | XSS、CSRF、CORS、Cookie 策略 |
| 性能 | 首屏加载、懒加载、虚拟滚动 |
| 无障碍 | 键盘导航、屏幕阅读器、ARIA 标签 |

## 使用原则

1. **先通用后特异**：先生成通用用例，再补充平台差异
2. **不重复**：平台特异用例不重复通用逻辑
3. **标注来源**：`type: "platform-specific"` + `platform_notes`
4. **按平台知识**：利用 AI 内置的平台知识，无需额外维护模板
