# Raw(原始需求)

> Layer 0 — 用户的原始输入。可能是文本,也可能是文件引用。

## 建议格式

```markdown
# 原始需求

{文本描述,或文件引用,或两者结合}

项目地址(可选): {path} 或 "假设"
```

## 示例

### 示例 1: 文本描述

```markdown
# 原始需求

想在 RN 框架里新增登录界面,快速实现视觉效果。

项目地址: ~/Project/QiPDA/
```

### 示例 2: 文件引用

```markdown
# 原始需求

文件: ./用户原始需求/2026-06-05-login.md

项目地址: ~/Project/QiPDA/
```

### 示例 3: 无项目地址

```markdown
# 原始需求

想在 RN 框架里新增登录界面,快速实现视觉效果。

项目地址: 假设 React Native 项目,标准结构
```

## 放什么

- 用户原始抱怨
- 会议纪要
- 需求文档
- Bug 报告
- 文件引用
- 任何尚未形成 PRD 的材料

## 命名

`{YYYY-MM-DD}-{简短主题}.md`

## 下一步

Agent 读取 raw,开始项目扫描,然后产出 `prd/{date}-{topic}/{topic}.md`。
